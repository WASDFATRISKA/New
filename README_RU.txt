EVOLUTION 2.0 — версия-прототип

В приложении:
- единая навигация: обзор, тренировки, ЕГЭ, прогресс;
- календарь тренировок;
- отдельные карточки упражнений и подходов;
- вес, повторения и необязательный RIR для каждого подхода;
- редактирование и удаление тренировок;
- журнал занятий по профильной математике, русскому и информатике;
- локальное сохранение в браузере;
- экспорт резервной копии JSON;
- базовый автоматический анализ тенденций по упражнениям.

ВАЖНО:
1. Автоанализ в этой версии — прозрачные правила сравнения записанных тренировок, а не подключённая нейросеть.
2. Для AI-модели в будущем потребуется серверная часть и API-ключ. Не размещайте секретный API-ключ в app.js или других публичных файлах GitHub Pages.
3. Демонстрационных официальных заданий ЕГЭ в этой версии нет. Ссылку на демоверсии ФИПИ можно открыть из раздела ЕГЭ.
4. Данные хранятся в localStorage конкретного браузера/устройства. Для синхронизации между устройствами нужна отдельная база данных и авторизация.
5. Не очищайте данные браузера без резервной копии. Используйте «Экспорт JSON».

Публикация:
- распакуйте архив;
- загрузите ВСЕ файлы в корень GitHub-репозитория;
- Settings -> Pages -> Deploy from a branch -> main -> /(root);
- откройте выданную GitHub Pages ссылку по HTTPS;
- в Chrome на Samsung: меню ⋮ -> Добавить на главный экран / Установить приложение.

Это рабочий прототип интерфейса и журнала, а не финальная версия с облачной синхронизацией или настоящим AI.
